# Review handoff

The user says the earlier figures have more character and the new versions are too generic. This pair restores distinct cost-channel, clustering and asymmetric-flow motifs, with restrained shared colors and readable print typography. Figure1 is the unified view with no experiments; Figure2 is the framework. This is a separate review branch, not a replacement of R3 or the manuscript.

Delivered: Figure1_Identity_R1 and Figure2_Identity_R1 as native PPTX, SVG, vector PDF, 300dpi PNG, grayscale and CVD previews. Figure1 is5.5×3.17in; Figure2 is5.5×3.3in. Minimum text8.107pt, math/scripts8.169pt. Zero raster objects. Math is editable grouped vector contours with exact LaTeX, not semantic OfficeMath. Actual LibreOffice export verified; PowerPoint rendering unverified.

Each main module can be moved as a group, and ordinary child text remains editable. Formula glyphs are separate native contours inside equation groups. External connectors do not auto-reroute. Scene, font and validation records are included; native_export.py adds the formula groups to the scene skeleton.

Aesthetic acceptance is pending. The generated A/B references and first-print native previews remain in the comparison history. No experimental values or manuscript source changed. Submission PDF/SVG metadata are anonymous.

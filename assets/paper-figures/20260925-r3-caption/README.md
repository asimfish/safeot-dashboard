# SafeOT conceptual figures

Native PDF/SVG/TeX,300dpi print previews,grayscale and color-vision previews,and font reports. Figure1 follows the three-part conceptual caption. Side curves are schematic. Figure2 uses the benchmark's empty hard-edge mask; graph targets are never executed.

Raw projection duals are lambda*; clipping/filtering produces lambda_bar*. Exact settings and conditional limits are separated. The normalized actor advantage appears in Figure2. Figures are anonymous. Visual acceptance by an independent reviewer remains pending.

Rebuild: extract editable_sources.zip, run python3 source/build_figures.py and python3 source/make_accessibility.py. Requires TeX with newtx and TikZ, PyMuPDF, NumPy and Pillow. Figure data is conceptual, not experimental.

# OriginalTemplate_R4 handoff

This is a separate candidate from immutable OriginalTemplate_R3. The old template layout and current SafeOT content are preserved. Accent colors are restored to the earlier vivid blue/green/orange palette. Four Figure1 decorative cost icons and two Figure2 rollout/agent icons are generated transparent PNG assets from the built-in imagegen route and inserted as independent movable PPT picture objects; they are not reconstructed with PPT primitives. The scientific graphs, arrows, labels, equations and layout remain native or vector-contour objects.

R3 and the F02 R5/R6 history remain unchanged. Actual LibreOffice rendering, PDF metadata, 8pt floor, gray/CVD previews, PPTX CRC, native label edit and independent generated-icon move probes pass. The exported PDF/SVG contain the six generated icon rasters; this boundary is intentional and recorded in the reports. PowerPoint-native rendering is unverified.

# Earlier attached PDF → editable PPT, first

This package contains ONLY the historical Figure1/2 reconstructions from the user-attached PDF (pages3/6). It does not contain the SafeOT-adapted copies or F02 R4. Original content, palette, layout and aspect ratios are retained as reconstruction targets; the method names and formulas have not been modernized.

Open Figure1_OriginalEditable.pptx and Figure2_OriginalEditable.pptx. The corresponding300dpi PNG/PDF/SVG files are actual PPTX exports via LibreOffice. Figure1/2_PDF_original.png are exact extracted source pixels. The PPTXs are byte-identical to the previously delivered faithful branch; no new redesign has been performed.

Text, panels, matrices, graph elements, arrows and traced schematic curves are native editable objects. Small source pictograms remain independent images. Formulas are grouped vector contours with LaTeX source, not semantic OfficeMath. Liberation Serif/newtx substitute the raster fonts, so this is not a pixel-identical copy. The original small print is retained for fidelity and is not the final paper-size typography. PowerPoint rendering has not been independently verified; LibreOffice rendering and group/child editing were checked.

Review the old-layout conversion first. Current-architecture adaptations and F02 revisions remain separately preserved in history. Their promotion is not implied by this package.

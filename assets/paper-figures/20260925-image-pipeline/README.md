# SafeOT figure candidates

Figures 1 and 2 each have two S5 formal candidates, F01 and F02. Four S2 exploratory candidates per figure are retained as history. Each image is the original generated raster, with its exact prompt and SHA-256 recorded. No winner has been chosen.

S0/S1 source grounding, S2 generation, S3 exploration review, S4 formal prompt preparation, and S5 generation are recorded separately. S5 registration/provenance gates pass; these gates do not certify scientific accuracy, print fonts, or publication quality.

After the user or mentor selects one candidate per figure, the approved workflow continues with pinned super_img2ppt: native editable PPTX, SVG, then vector PDF, with actual slide-render verification of math, connectors, minimum 7 pt fonts at 5.5 in width, and anonymous export. These raster candidates are not the final submission files. Manuscript promotion remains with the owner.

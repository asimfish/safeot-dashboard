# Modular Figures 1–2, R3

Publication candidates are anonymous native vector PDFs with embedded NewTX/TeX Gyre Termes fonts. Figure1 is 5.5 × 2.9 in; Figure2 is 5.5 × 2.3 in. Both have a minimum actual PDF font size of 7.1731 pt. Figure1 has 32 text labels including eight axis ticks. No raster image is embedded in either PDF.

Use Figure1.pdf / Figure2.pdf at exactly 5.5 in. TeX is the authoritative editable source; outlined SVG is supplied for vector editing. The old PPTX remains a historical source and is not represented as a matching R3 file. RGB print previews are 300 dpi; grayscale, protanopia and deuteranopia previews are diagnostic alternatives. Figure captions contain 63 and 70 words.

Rebuild: unzip editable_sources.zip into an empty directory and run `python3 source/build_figures.py`; then `python3 source/make_accessibility.py`. Requires a TeX installation with newtx and TikZ, PyMuPDF, NumPy and Pillow. The archive contains only renderers and frozen figure data; website publishing and project workflow tools are excluded.
